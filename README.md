==================================================

DESIGN DIRECTION

==================================================

Create a high-end, modern fitness website with a bold editorial aesthetic.

Visual style:

- Black, white, charcoal and subtle gray palette

- Minimal use of color

- Large cinematic fitness photography

- High contrast

- Bold uppercase typography for headings

- Clean modern sans-serif typography

- Large whitespace

- Sharp rectangular buttons

- Thin borders

- Subtle animations

- Premium athletic/editorial feeling

- Strong visual hierarchy

- Avoid the typical generic "gym website" look

The reference image has:

- Full-width hero image

- Dark/black-and-white photography

- Minimal transparent navigation over hero

- Large uppercase headline

- Small eyebrow text

- Strong CTA

- Clean white sections below the hero

- Large typography

- Magazine/editorial composition

Use this design language throughout the website.

==================================================

RESPONSIVE DESIGN

==================================================

The website must be fully responsive.

Desktop:

- editorial multi-column layouts

- large typography

- cinematic images

Tablet:

- adapt grids to 2 columns

Mobile:

- single-column layout

- large readable typography

- sticky mobile CTA

- hamburger navigation

- optimized image sizes

- buttons full-width where appropriate

Ensure no horizontal scrolling.
